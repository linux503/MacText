能力

够用，不过度

日常真正会用到的能力——标签、项目树、搜索、命令面板、字体大小——为原生体验与秒开而打磨。

多标签编辑

打开 / 保存 / 另存为 / 关闭，未保存提示；中键关闭。

项目侧边栏

浏览文件夹树。⌘B 完全隐藏，不留空白边条。

查找与替换

内联查找栏，上一个 / 下一个，Esc 关闭。

命令面板

⌘⇧P 切换主题、跳转行、侧边栏等。

语法高亮

Swift、Python、JS/TS、JSON、Markdown，配色贴合 Ink。

会话恢复

标签、未保存内容、光标、文件夹、主题与窗口。

外观

四套校准主题

Ink 是标志性外观——炭黑、石灰绿、铜金——与程序坞图标一致。
