能力

够用，不过度

日常真正会用到的能力——标签、项目树、搜索、命令面板、多行缩进、字体大小——为原生体验与秒开而打磨。

多标签编辑

打开 / 保存 / 另存为 / 关闭，未保存提示；中键关闭。

项目侧边栏

浏览文件夹树。⌘B 完全隐藏，不留空白边条。

查找与替换

内联查找栏，上一个 / 下一个，Esc 关闭。

命令面板

⌘⇧P 切换主题、跳转行、侧边栏等。

语法高亮

Swift、Python、JS/TS、JSON、Markdown，配色贴合 Ink。

会话恢复

标签、未保存内容、光标、文件夹、主题与窗口。

拖出标签

拖到桌面成新窗口，或拖入另一窗口合并。

Sublime 编辑

复制 / 移动 / 删除 / 合并行、注释、括号跳转、自动缩进。

自动保存

会话备份缓冲；已有路径的文件会自动写盘。
