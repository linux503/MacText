Features

Built for daily writing & code

The 1A essentials—fast to open, light on memory, keyboard-first.

Multi-tab editing

Open, save, save-as, close with dirty-file prompts. Middle-click to close.

Folder sidebar

Browse a project tree. Hide completely with ⌘B—no leftover gutter.

Find & replace

Inline find bar, next/previous match, Esc to dismiss.

Command palette

⌘⇧P for themes, go-to-line, sidebar, and common actions.

Syntax highlight

Swift, Python, JS/TS, JSON, Markdown—with Ink-matched colors.

Session restore

Tabs, unsaved text, caret, folder, theme, and window frame come back.

Screenshots

Ink theme in focus

Charcoal canvas, lime accents, amber caret—matched to the Dock icon.

Shortcuts that stick
