Capabilities

Essential, not excessive

The core workflow you use every day — tabs, project tree, search, palette — tuned for native feel and instant launch.

Multi-tab editing

Open, save, save-as, close with dirty prompts. Middle-click to dismiss a tab.

Project sidebar

Browse a folder tree. Hide fully with ⌘B — no leftover gutter strip.

Find & replace

Inline find bar, next/previous match, Esc to close without friction.

Command palette

⌘⇧P for themes, go-to-line, sidebar, and everyday actions.

Syntax highlight

Swift, Python, JS/TS, JSON, Markdown — colors matched to Ink.

Session restore

Tabs, unsaved text, caret, folder, theme, and window frame return intact.

Appearance

Four calibrated themes

Ink is the signature look — charcoal field, lime accents, amber caret — aligned with the Dock icon.
