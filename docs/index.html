Capabilities

Essential, not excessive

Daily workflow — tabs, project tree, search, palette, multi-line indent, font size — tuned for native feel and instant launch.

Multi-tab editing

Open, save, save-as, close with dirty prompts. Middle-click to dismiss.

Project sidebar

Browse a folder tree. Hide fully with ⌘B — no leftover gutter.

Find & replace

Inline find bar, next/previous match, Esc to close.

Command palette

⌘⇧P for themes, go-to-line, sidebar, and actions.

Syntax highlight

Swift, Python, JS/TS, JSON, Markdown — Ink-matched colors.

Session restore

Tabs, unsaved text, caret, folder, theme, window frame.

Multi-line indent

Select any part of multiple lines — Tab / ⇧Tab / ⌘] / ⌘[ indents whole lines, Sublime-style.

Tear-off tabs

Drag a tab out to a new window, or drop it onto another window to merge.

UI language

Chinese by default. Switch anytime in Settings (⌘,).

Sublime editing

Duplicate / move / delete / join lines, toggle comment, matching brackets, auto-indent.

Auto-save

Buffers session-backed; files with a path write to disk automatically.

Updates

Auto-checks GitHub Releases on launch; About / Help link to site & GitHub.

Ink is the signature — charcoal, lime, copper — aligned with the Dock icon.
