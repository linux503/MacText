Capabilities

Daily workflow — tabs, project tree, search, palette — tuned for native feel and instant launch.

Multi-tab editing

Open, save, save-as, close with dirty prompts. Middle-click to dismiss.

Project sidebar

Browse a folder tree. Hide fully with ⌘B — no leftover gutter.

Find & replace
